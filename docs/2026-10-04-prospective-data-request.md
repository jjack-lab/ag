# 前瞻性确认数据素材要求（一页清单）

> 用途：星牧智控（牛只视觉识别与健康风险辅助筛查）在论文与验收中需要**一批全新的、未被任何开发环节使用过的影像数据**，用于"独立确认"。本页可直接转发给牧场或合作方。

## 一、我们需要两类素材

**A. 行为视频（用于行为识别模型的独立确认）**

- 牛舍固定摄像头连续录像：同一栏舍、同一机位，建议连续 3–7 天，白天与夜间（红外）都要有；
- 画面里最好同时出现**站立采食 / 饮水 / 站立反刍 / 卧息反刍**这四类日常行为；
- 提供**原始文件**，不要剪辑、不要转码、不要压缩（我们会自己抽帧）；
- 最低量：**≥ 5 个不同机位/时段**的源视频、每类行为**≥ 60 段可用片段**（约 5–10 分钟录像通常够）。

**B. 检测影像（用于目标检测模型的独立确认）**

- 与上面同源的牛舍图像或视频（也可单独提供）：建议 **≥ 300 张**不同场景/光照的照片，或等量的短视频；
- 若画面里有羊、骆驼等其它物种，也请一并提供并标注大致类别（模型目前覆盖 6 类）；
- 同样提供原图/原视频，不要加滤镜或压缩。

## 二、请随数据一并说明

| 项 | 说明 |
| --- | --- |
| 来源 | 牧场/场区代号（可用化名）、所在地（可只到市/县）、采集日期区间 |
| 设备 | 摄像头型号或手机型号、机位高度与角度、分辨率/帧率 |
| 场景 | 存栏规模、品种、栏舍类型（室内/半开放/运动场）、大致光照条件 |
| 时段 | 白天/夜间各占多少，是否有补光 |

不需要提供：牛只个体编号、耳标、免疫记录等任何可识别个体或涉及经营隐私的信息。

## 四、暴露声明（很重要，决定数据能否作为"独立确认"）

请确认：

- [ ] 该批影像**未上传到任何公开数据集**、未在网络上公开；
- [ ] 该批影像**未用于本项目任何历史模型训练或参数调整**；
- [ ] 该批影像**不是**此前提供给我们的那批数据的重新剪辑版本。

我们会对你提供的每个文件计算 SHA-256，并与已有 397 个开发期源视频的登记表逐条比对：**只要有一个文件与开发数据重合，整批会被拒收**（这是为了保护论文结论的可信度，不是不信任）。

## 五、交付方式

- 把原始文件放到任意一个目录（例如 `E:\大创\prospective_2026q4\`），或提供网盘链接；
- 告知目录路径即可，剩下的（哈希登记、按源视频划分冻结、暴露边界校验）由我们一条命令完成，不需要你处理格式。

## 六、我们会怎么用（承诺）

- 该批数据**只读一次**、只用于最终确认评估，**不用它调参**、不用它挑选模型；
- 报告结果时会同时给出**均值、波动区间**与**逐类指标**，不只报最好看的总分；
- 若结果不理想，我们**照实发表**（此前的负结果已按同样方式记录在案）；
- 数据只保存在本机受控目录，不随 Git 仓库分发。
