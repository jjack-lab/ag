# 健康模型分析页验收（2026-10-22）

## 功能与数据流

本地网页左侧进入“健康模型分析”，选择已完成牛视频后，网页调用 `GET /api/jobs/{job_id}/health-assessment`。接口按视频内 Track ID 合并任务结果中的规则健康证据、行为摘要以及单独保存的人工复核记录。页面提供规则分数与来源、综合分析、行为时长、无法确定时长、人工记录和返回原视频入口。背景粒子为纯 CSS 动效，系统设置减少动态效果时停止动画。

健康模型沿用 `health_monitor.py` 的规则型轨迹筛查评分。综合分析把规则提示、主要行为、无法确定时长及复核状态写成可读说明；行为预测不改变规则分数，也不自动覆盖人工结论。羊视频不生成牛健康评分，接口返回 422。

## 本地演示结果

正式本地任务 `202d89f9aaad433480d8570bd90c3d41` 的接口返回 26 个视频内 ID、26 个有规则提示的轨迹、0 条人工复核。8 个 ID 有可用行为摘要；例如 ID 2 为规则分数 40、卧姿休息 19.5 秒、无法确定 1.5 秒。浏览器实际打开分析页并查看该 ID 的规则证据、行为数据与粒子视觉；没有向正式库写入测试复核。

浏览器截图保存在被忽略的 `data/verification/health-insights-browser.png`。该视频为参与过开发的真实拍摄素材，不能用于独立牧场效果或疾病预测结论。后续需带现场观察与诊疗依据的授权视频，评估规则误报、行为可判读率与人工核查价值。
