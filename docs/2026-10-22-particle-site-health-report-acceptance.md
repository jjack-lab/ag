# 粒子网站与健康报告验收（2026-10-22）

## 本轮实现

- 沿用 React + JavaScript 前端和 Python API，重做网站首屏与工作区视觉。首屏增加 72 个确定性粒子、光晕、轨道和健康信号展示，展示最近牛视频的真实 Track ID 数；系统设置“减少动态效果”时停止动画。
- “健康模型分析”页增加“生成健康报告”入口。报告直接使用已完成牛视频的 `/api/jobs/{job_id}/health-assessment` 数据，列出任务/处理时间、分析模型、轨迹概览、每个视频内 ID 的规则分数、主要行为、无法确定时长、规则证据和人工复核。弹层可关闭；打印按钮调用浏览器打印对话框，可由用户选择“保存为 PDF”。打印样式只保留报告正文。
- 保留原视频识别、告警、人工复核、圈舍盘点等现有工作区功能和接口。PHP 未引入，因为现有 JavaScript 页面可直接复用这些链路。

## 边界

报告来自单次视频的规则型风险筛查与行为摘要，不能诊断具体疾病或预测发病时间。开发素材不算独立牧场验证；视频内 Track ID 不代表跨视频身份。
