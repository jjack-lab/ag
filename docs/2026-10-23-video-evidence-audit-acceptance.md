# 视频识别与空间事件核对：本轮验收

## 已交付的核对链路

- 固定机位区域报告现在输出每次进入的 Track ID、视频秒数和按已检测帧累计的停留秒数；栏门报告继续输出每次穿线方向与时间。
- 视频面板可跳到事件时间、逐条标“正确 / 误报 / 栏门方向错误”，补录漏掉的进入或穿线，填写核对人和备注。确认已回看完整视频且全部自动事件已判定后，才显示本视频事件级 Precision、Recall。未完成时只显示核对进度。
- 栏门同时显示“视频自动计数”和“人工核对计数”。后者会剔除误报、翻转方向错误并加入补录漏计；仍需与真实出入栏台账逐次核对，不自动更新存栏。
- 人工结论保存于当前任务结果目录，绑定空间报告内容哈希。重新画区或重算报告后，旧核对不混入新报告。
- 若整段视频没有检测轨迹，面板明确提示 0 次区域进入或穿线不能推断空栏、未采食或无人出入。

## 检测精度的现有证据

公开 ICAERUS 羊视频 `crop_23.11.23-12.MP4` 有 99 帧、1,956 个真值框。已保存的同源评测中，交付模型框级 TP 2 / FN 1,954，Recall 0.102%；ICAERUS 羊专用演示模型 TP 1,722 / FP 257 / FN 234，Recall 88.04%。后者与视频同属 ICAERUS 项目，训练集重叠未排除，不能作为独立牧场效果。原始测量与哈希见 `data/verification/icaerus_sheep_20261014/evaluation.json` 和 `docs/2026-10-14-icaerus-sheep-model-demo.md`。

本轮用本地 CBVD-5 `272.mp4`（画面固定、饲槽可见，250 帧）直接运行交付模型，参数为牛类别 1、置信度 0.25、NMS IoU 0.45，得到 **0 条牛检测轨迹、饲槽附近观察区进入 0 次**。静帧可见多头牛；类别映射 `{0: sheep, 1: cattle}` 无误。单帧诊断在阈值 0.1 只有 1 个候选，在 0.05 只有 2 个，不能把降低阈值作为精度修复。该段没有逐帧检测框真值，不能计算严格 Recall；它可作为明显漏检案例，不能验证区域进入或趋势精度。运行产物保存在被 Git 忽略的 `data/verification/video_evidence_audit_272/`。

## 下一批具体工作与所需数据

1. **识别精度**：先获取未参与开发的牛、羊原视频及框标注，按机位分组；在开发集比较原模型、候选模型及阈值，固定方案后在独立机位测试框级 Precision/Recall、ID 切换。对 `272.mp4` 的漏检先做人工框标注，再定位尺度、遮挡和背景域差异。训练或阈值不能用正式测试集反复选择。
2. **可回看告警**：现有截图、前后片段和任务状态可继续使用；现场人员逐条标误报、漏报并核对是否能凭证据完成处置。在线“长时间无检测”须提供稳定视频源、断流口径和运行主机后接入，当前仅分析上传文件。
3. **手机处置**：用实机让现场人员走通“证据 → 已查看/误报/已处理 → 备注 → 复查”，记录误触和耗时。消息推送需先确定牧场接收渠道和网络条件。
4. **区域趋势**：需同圈舍、同机位、同画区、真实起始时间的连续多日视频，每段至少 10 分钟；人工标注进入和停留以计算事件误差。`272.mp4` 只有 10 秒且该模型 0 轨迹，不能演示有效趋势。
5. **栏门计数**：需固定栏门机位的完整经过视频及逐次人工出入栏台账。用本轮核对页标方向错误、折返、漏计、遮挡和 ID 切换，再比较人工核对数与台账；未通过前不将视频数当存栏。
