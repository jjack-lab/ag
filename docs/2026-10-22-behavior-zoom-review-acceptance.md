# 行为局部放大人工复核验收（2026-10-22）

## 使用

启动本地服务后打开 `http://127.0.0.1:5173/`，点击首页“真实拍摄牛视频 · 开发素材演示”的“打开演示视频”。在“行为局部放大复核”中选择视频内 Track ID，暂停结果视频或按前移/后移按钮定位时间。页面并列显示原视频完整帧和该 ID 检测框附近的原始像素裁剪；下方播放器可回看前后动作。人工选择观察结论，填写说明并保存，记录会出现在同任务的人工复核列表中。

## 实现与验收

- `GET /api/jobs/{job_id}/inspection-frame` 从任务原视频按时间读取帧；`crop=true` 时用同帧轨迹 CSV 的 Track ID 检测框定位裁剪，返回 JPEG。缺少该 ID 时返回 404，页面提示前后跳帧。
- 人工结论复用现有视频复核记录接口，保存 Track ID、秒数、结论和备注；模型行为输出不被改写。“仍无法判断”保存为 `uncertain`。
- 正式演示任务 `202d89f9aaad433480d8570bd90c3d41` 在本地浏览器实际加载：原帧 640×640，Track ID 1 在 0 秒的局部裁剪 101×101，截图为 `data/verification/behavior-zoom-browser.png`（本机验证文件，未入库）。未向正式库写入演示复核结论。
- 后端全量 `672 passed, 4 skipped`；前端全量 `59 passed`；`npm run build` 成功。

## 边界

裁剪只是放大原始像素，不能恢复被遮挡或模糊的细节，也不能据此推断疾病。该演示来自已有牛开发素材，人工结论需现场人员对原视频及上下文核对。Track ID 只在本视频内有效。
