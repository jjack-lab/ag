# 沉浸式首页设计

## 目标

借鉴用户指定的 ChatGPT Site「Planet Jumping」的全屏场景、超大标题、中央入口和镜头转场，为星牧智控制作可演示的牧场首页。用户已选择“沉浸式首页 + 清晰工作台”。

## 页面结构

- 首页占满首屏，以仓库现有的真实拍摄牛开发素材静帧作背景，并明确标注“开发视频演示素材”。背景只作展示，不作为当前实时监控画面。
- 顶部保留品牌、识别能力、健康报告、告警等入口；中央用醒目的“进入健康控制中心”按钮引导进入工作台。
- 巨型标题、简短说明、少量真实数据摘要与细粒子营造空间感。不能把单视频 Track ID 称作牛群总数。
- 点击主入口时播放短镜头推进，并滚动到工作台；使用减少动态效果设置时跳过推进。
- 工作台继续使用现有识别、健康分析、报告、告警、核查、盘点组件和 API；只统一视觉层，不改健康判断逻辑。

## 约束与验证

- 手机宽度下标题和按钮可读、可点，首页不会遮挡工作台。
- 现有深链接和导航仍可抵达识别能力、健康报告和告警。
- 测试入口交互和减少动态效果，运行前端测试与构建，并在浏览器检查桌面和手机宽度。
