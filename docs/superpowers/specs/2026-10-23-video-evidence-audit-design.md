# 视频识别与空间事件核对设计

## 目标与范围

网站视觉工作暂停。本阶段把现有视频结果变成可人工核对、可量化误差的证据链。先支持已上传视频；不把公开短视频当作持续摄像头或牧场现场验收。健康规则仍只给待核查提示，不输出疾病诊断。

## 现状

- 检测评测中心已能用逐帧标注计算框级 TP、FP、FN、Precision、Recall、F1 和 ID 切换；ICAERUS 羊样例的默认模型 Recall 约 0.1%，羊专用演示模型在同源数据约 88%，后者不是独立泛化证据。
- 告警已有时间点、截图、前后片段和核查事项；手机端事项已有状态、备注与复查记录。
- 固定机位报告已有矩形区域进入/停留与栏门线穿越统计，但区域和栏门事件还没有逐条真值核对；同机位长视频与人工出入栏台账尚未取得。

## 首个可独立交付单元：空间事件人工核对

每份已完成的区域或栏门报告展示事件清单。人工可逐条打开对应视频时间点，标记“正确、误报、方向错误”，补录漏掉的真实进入或穿线事件，并写备注。核对结果关联视频任务、报告类型和画区版本；修改画区并重算报告后，旧核对结果不再混入新报告。页面展示自动事件数、人工确认数、误报数、漏报数、方向错误数和核对进度；这些数只代表已核对事件，不自动推断真实存栏。

区域活动需把每次进入的时间、Track ID 和该次停留时间作为可核对事件输出，已有总量与小时趋势继续保留。栏门事件保留方向和时间。人工补录为独立真值事件，可附台账时间、方向和备注；同日汇总明确区分“视频自动计数”与“人工核对计数”。

## 精度测量与改进决策

框级检测继续用现有标注评测接口，不从 Track ID 数估算检测精度。空间事件核对完成后报告事件级 Precision、Recall、误报/漏报及方向错误；未全部核对时显示“部分核对”，不发布完整精度结论。优先分析漏检、遮挡、ID 切换、重复穿线和画区偏差，再在开发集上做模型或阈值对比，冻结独立测试集后才宣称精度提高。外部羊专用模型只做显式实验候选，需先查权重许可与训练集重叠。

## 后续单元与现场依赖

1. 告警：把空间事件和核对结果联到现有截图、片段与核查事项；用人工结论统计告警误报率。连续“无检测”需接入持续视频源后才增加在线监控。
2. 手机：核对与处置表单按窄屏可点、可读和完成耗时验收；消息推送须先选定牧场实际接收渠道。
3. 趋势：仅在同圈舍、同机位、同画区、真实时间戳且每段至少 10 分钟的视频间比较，展示样本天数和覆盖时长；取得多日素材后人工核对进入与停留误差。
4. 栏门：取得固定机位完整经过视频与人工出入栏台账，逐次核对方向、折返、遮挡和 ID 切换。只有经现场核对后，日报才可作为交接辅助；视频计数不自动写入存栏数。

## 验收

- 构造含正确、误报、漏报、方向错误的短测试视频/轨迹，核对页与 API 数字一致。
- 人工核对后可从报告跳到对应视频时间点；窄屏可完成标注、备注和任务处置。
- 在已有 CBVD-5 `272.mp4` 上演示单段饲槽附近观察区；不声称跨日趋势已验证。
- 检测精度报告清楚区分默认模型与外部模型、同源样例与独立测试。
