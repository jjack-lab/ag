# 启动器与全按钮交互设计

## 目标

为 `F:\new大创` 增加可双击运行的 Windows 启动与停止入口，并让当前网页中所有可见按钮、导航、告警项和结果链接产生明确、可验证的交互结果。

## 范围

### Windows 启动入口

- 新增根目录 `启动项目.bat`，从脚本所在目录启动，不依赖用户当前工作目录。
- 脚本设置项目已验证的 Python：`F:\deepl\anaconda1\envs\pytorch\python.exe`，随后调用现有 `start_delivery.ps1`。
- 服务成功就绪后自动打开 `http://127.0.0.1:5173`。
- 启动失败时显示中文提示并保留窗口，方便查看错误。
- 新增根目录 `停止项目.bat`，调用现有 `stop_delivery.ps1`，显示停止结果。
- PowerShell 脚本继续作为真实启动逻辑的唯一实现，BAT 只负责易用入口，避免两套启动逻辑分叉。

### 单页功能切换

侧栏维护一个活动视图状态，包含：

- `overview`：今日工作台，展示指标、识别工作台和摘要。
- `monitor`：实时监控，聚焦图片/视频识别工作台和结果区域。
- `alerts`：健康告警，展示完整告警列表。
- `cattle`：牛只档案，根据现有告警和检测数据汇总可用的牛只记录；无数据时给出明确空状态。
- `analytics`：数据分析，根据仪表盘数据与告警级别生成可解释的统计卡片；不伪造后端尚未提供的历史趋势。

点击侧栏按钮会更新活动样式、切换主面板，并把视图滚动到工作区域。顶部“进入健康控制中心”和“开始视频识别”会聚焦相应区域。“查看全部”切换到健康告警视图。

### 告警交互

- 告警行是可操作按钮。
- 点击后展开或显示告警详情，包括牛只编号、风险等级、原因、处置建议、发生时间和置信度。
- 再次点击同一告警可收起详情。
- 所有按钮提供 `type="button"`、可访问名称和可见焦点状态，避免表单外按钮产生隐式提交。

### 识别与下载入口

保留现有图片/视频模式切换、文件选择、参数调整、识别提交、健康报告打开和结果文件下载。识别运行时提交按钮禁用并显示处理中状态，这是有意的防重复提交行为，不算无响应。

## 数据流

页面启动时继续并行读取 `/api/dashboard` 与 `/api/alerts`。视图切换只改变前端展示，不触发虚构请求。告警、档案和分析视图复用已经获取的数据；API 失败时每个视图都展示可理解的错误状态。识别工作台继续使用现有识别和异步任务 API。

## 错误处理

- BAT 检查已验证 Python 是否存在；不存在时给出路径与修复提示。
- PowerShell 预检、端口占用或服务启动失败时，BAT 传播非零退出码并暂停。
- 浏览器无法自动打开不应终止已经成功启动的服务，但应显示可手动访问的 URL。
- 前端数据请求失败时保留导航可用，并显示服务不可用提示。

## 测试与验收

- 先为导航切换、“查看全部”、告警展开和启动 BAT 契约编写失败测试，再做最小实现。
- 运行 React 测试、Python 测试和生产构建。
- 执行启动脚本预检，并验证 BAT 调用正确的 PowerShell 脚本与 URL。
- 在真实浏览器逐个点击可见按钮、链接和选项，确认活动视图、详情、上传、提交及下载入口都有明确响应。
- 启动与停止后检查 8000/5173 端口和项目进程状态。

## 非目标

- 本轮不新增摄像头硬件协议、用户登录、疾病诊断模型或新的后端历史统计 API。
- 健康结果继续定位为风险筛查，不作为兽医诊断。
