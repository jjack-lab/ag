# 模块化入口与入场转场设计

用户选择 Planet Jumping 风格的百分比加载层、穿过中央入口的转场、模块选择页和八个独立前端地址。当前 React 前端继续调用既有 Python API，不新增对外后端 API。

## 页面

- `#/` 是沉浸式牧场首页。首次加载显示短时 0–100% 进度层，随后展示真实开发牛视频静帧和中央入口。减少动态效果设置下直接显示页面。
- 点击中央入口后，独立的牧场画面窗口从按钮位置扩展至全屏；箭头和按钮文案立即退场。镜头继续向画面内推进，牧场画面逐渐过渡到蓝紫色星云空间，再显露 `#/modules` 的模块卡片。首页快捷入口直接进入目标模块。
- `#/modules` 是模块选择页，展示概览、视频识别、健康分析、告警、处置待办、牛只档案、数据分析和圈舍盘点八个入口。
- `#/module/<name>` 是独立模块页，仅渲染对应模块内容。概览只保留关键指标与模块入口，不再内嵌完整识别工作台和长告警列表。
- 所有模块页保留返回模块选择页与首页的入口。刷新、前进和后退应恢复地址对应页面。

## 数据与边界

- 沿用现有 `fetchDashboard`、`fetchAlerts` 和各模块 API；首页数字仍是最近一次牛视频的 Track ID 数，不是存栏数。
- 演示静帧继续标注开发素材来源；转场只改变呈现，不新增疾病判断。
- 页面路由采用 hash，避免本地静态服务为深链接增加回退配置。

## 验收

- 入口进度与“牧场画面扩展 → 景深推进 → 星云空间 → 模块页出现”的连续转场可见；不是单纯放大箭头。减少动态效果时可以直接进入。
- 八个模块可由独立网址直接打开，页面只显示当前模块，浏览器前进/后退可用。
- 既有视频证据跨模块跳转仍可打开原任务；前端全量测试和构建通过。
