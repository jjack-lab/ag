# 跨牧场牛只行为识别鲁棒性实验设计

## 目标

在不使用外部测试标签调整现有 CVB-X3D 模型、温度或拒识阈值的前提下，使用有明确来源的公开牛只视频建立跨牧场评测，量化域偏移造成的性能下降，并验证“模型不确定性 + 视频质量 + 时序一致性”选择性拒识能否降低错误接受风险。实验必须可复现、可追溯、可用于比赛答辩和论文消融。

本阶段只使用 `F:\new大创`。任何下载、解压、缓存、实验输出和文档均不得写到项目外。VLM、多模态推理和具身设备控制固定为最后的后续研究阶段，本轮不下载或运行 VLM。

## 研究问题

1. 现有模型从 CVB 迁移到不同牧场、摄像机、光照和牛群密度的公开视频后，分类、校准和覆盖率下降多少？
2. 已冻结的温度缩放和置信度/熵拒识策略能否在外部数据上保持风险控制能力？
3. 亮度、模糊、牛框完整度、轨迹连续性和相邻窗口预测一致性是否能进一步减少错误接受？
4. 面对模糊、低亮、遮挡、降采样、掉帧和压缩噪声时，系统是否会合理增加拒识，而不是产生错误高置信输出？
5. 若零样本跨域性能不足，严格分组的少样本适配能否在不污染测试集的情况下改善结果？

## 数据源选择

### 域内数据

现有 CVB 数据和检查点继续作为训练域、验证域和域内基线。检查点、校准参数和策略阈值在外部测试前冻结。外部测试标签不得用于重新选择这些参数。

### 首选外部数据：CBVD-5

CBVD-5 论文报告 687 个视频片段、107 头牛、7 个摄像机以及站立、卧躺、采食、反刍和饮水五种行为，并公开指向 Kaggle 的数据入口。数据下载前必须读取并记录 Kaggle 数据页实际显示的许可；论文采用的许可不能自动视为数据文件许可。

只下载实验所需的 `video_cut`、标注和元数据，下载预算上限为 `5 GiB`。若 Kaggle 文件只能整体下载且超过预算、需要未获授权的凭据、许可含糊或关键标注不可用，则停止，不绕过限制，并按计划变更流程切换后备数据。

### 后备数据：MmCows

MmCows 数据卡标注为 `CC BY-NC-SA 4.0`，包含多视角 RGB、行为标注和多种传感器。由于连续视觉数据体量大、部分预览视频是 15 秒间隔采样，本轮只在 CBVD-5 受阻时选择不超过预算且适合时序评测的子集。若没有满足连续性要求的子集，则只完成数据工具和协议验证，不伪造跨域行为结论。

### 不采用的主方案

CattleEyeView 数据通过表单申请且行为标签不匹配；零散网络平台视频存在版权、失效和标签质量问题。二者可以登记为候选，但不作为本轮主测试集。

## 模块边界

- `external_registry.py`：读取和校验数据登记，不负责网络下载。
- `external_download.py`：预算、目标路径、下载、哈希和安全解压；通过注入下载函数进行离线测试。
- `cbvd5.py`：解析 CBVD-5 元数据和标注，保留原始标签。
- `external_clips.py`：按牛只和时间构造模型输入片段及溯源清单。
- `quality.py`：计算与模型无关的视频质量和时序质量特征。
- `cross_domain_experiment.py`：冻结协议、运行推理、比较方案、输出逐样本结果和汇总。
- `cross_domain_reporting.py`：只读取结构化结果并生成表格、Markdown 和图表。

模块之间通过不可变记录或 CSV/JSON 清单通信。下载器不能依赖模型；解析器不能选择实验阈值；报告器不能修改预测。

## 标签对齐

所有样本同时保存 `source_labels`、`mapped_label` 和 `mapping_tier`。

严格公共标签集：

- `foraging -> grazing`
- `drinking -> drinking`
- `rumination + standing -> ruminating-standing`
- `rumination + lying -> ruminating-lying`

扩展敏感性分析：

- `standing only -> resting-standing`
- `lying only -> resting-lying`

后两项是语义近似，不进入严格主结果。目标域没有标注的 `walking`、`running`、`grooming` 等类别不计算逐类监督指标，但其预测仍保留在逐样本文件中。无法唯一映射、冲突或缺少时间关联的样本进入排除清单，不猜测标签。

## 无泄漏协议

数据单位以原始视频、摄像机和时间段组成的 `source_group_id` 分组。任何适配、验证和测试划分必须以组为单位；同一原始视频的相邻裁剪不得跨组。排序使用 `SHA256(seed:source_group_id:sample_id)`，固定种子为 `20260823`。

第一轮零样本外部评测不划出外部验证集，也不使用外部标签调参。现有校准文件 `models/behavior/cvb_x3d_v2_calibration.json` 与检查点绑定并冻结。若启动少样本适配，必须先生成新的分组清单，测试组只在最终评估时读取。

## 实验协议

### 零样本跨域基线

比较：

1. 未校准 X3D；
2. 温度校准 X3D；
3. 温度校准 + 当前固定拒识；
4. 温度校准 + 质量感知拒识。

报告 Accuracy、Macro-F1、逐类 Precision/Recall/F1、NLL、ECE、Brier、覆盖率、可用行为覆盖率、接受样本 Macro-F1、选择性风险、不安全样本拒识召回率和推理时间。主表使用严格映射；扩展映射单独成表。

### 质量感知拒识

候选特征包括平均亮度、过暗/过曝比例、拉普拉斯模糊度、牛框面积比例、边界截断比例、检测置信度、轨迹连续率、缺帧率、相邻窗口预测一致性、最大概率、归一化熵和前两类概率间距。

首选可解释的门控或轻量逻辑回归。任何监督阈值只从 CVB 验证集学习，并满足已定义的最低可用行为覆盖率约束。若外部测试没有改善，保留负结果，不基于测试集回调阈值。

### 可控退化

对同一外部片段以固定种子生成模糊、低亮、局部遮挡、分辨率下降、随机掉帧和压缩噪声版本。每种退化有固定强度级别；原始片段是零级。报告性能和拒识随强度的变化，不把派生片段视为新的独立真实样本。

### 可选少样本适配

仅在严格公共标签集零样本 Macro-F1 明显不足且数据量允许时启动。比较每类 5、10、20 个片段，只微调分类头或最后阶段。适配集、验证集和测试集按 `source_group_id` 隔离。若没有稳定改善则停止，不扩大训练范围。

## 失败处理与计划变更

- 许可不明确：登记为 `blocked_license`，不下载或解压。
- 超过预算：登记估算大小并停止，选择更小文件或后备数据。
- 登录/凭据缺失：只使用官方公开流程；需要用户凭据时明确报告，不把凭据写入项目。
- 标注与视频无法关联：保留原始文件，样本进入排除清单。
- 视频损坏：记录哈希和解码错误，不删除原始证据。
- 外部标签映射不足：缩小主结果类别，不扩大语义映射。
- 指标未提升：报告负结果和限制，不改变测试协议。

任何事实性变化先更新本设计、实施计划、Goal 进度和数据说明文件，记录日期、原计划、变化原因、影响和替代方案，然后继续实现。

## 测试与验收

测试覆盖登记表、预算和哈希、安全解压、标签映射、分组防泄漏、片段溯源、质量特征、退化确定性、指标和报告。每项生产代码先写失败测试。网络下载通过小型本地 HTTP/注入函数测试；测试套件不依赖 Kaggle 在线状态。

完成标准：

1. 所有使用数据有官方来源、许可状态、项目内路径和哈希记录；
2. 外部测试清单可以从派生片段回溯到原视频；
3. 外部测试标签未参与模型、校准或门控参数选择；
4. 至少生成域内/域外对照、风险—覆盖率和退化曲线；
5. 结果文档如实区分严格映射、扩展映射和负结果；
6. Python、前端和交付测试按风险比例通过；
7. 不产生项目外写入。

## 最后阶段：VLM 与具身智能

主实验、报告和答辩原型完成后，才考虑让 VLM 对低可信片段进行零样本复核、时间定位和证据解释，并逐步接入 RGB/热成像、环境和个体历史。再后续才设计云台、巡检机器人或人工确认动作形成感知—推理—行动—反馈闭环。本轮只在研究路线中保留该方向，不实现模型推理或设备控制。
