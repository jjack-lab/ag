# 可信牛只行为识别实验设计

## 目标

在不重新训练现有 X3D 行为模型的前提下，对其输出置信度进行温度缩放校准，学习可复现的低可信拒识策略，并在独立测试集上比较未校准、仅校准、校准加联合拒识三种方案。实验产物必须能够支持论文消融表格，并能被运行时安全加载。

本阶段使用“低可信与不安全预测拒识”表述。CVB 的 `none`、`other`、`hidden` 是训练标签，不构成严格的开放集未知类；真正的开放集结论需要后续留一行为类重训练实验。

## 现有基础

当前 `BehaviorRuntime` 已实现：

- 固定最大概率阈值 `0.45`；
- 轨迹级指数概率平滑；
- 切换边界与连续确认迟滞；
- 将低置信度结果映射为“无法确定”。

本实验不重复这些功能，而是补充数据驱动校准、拒识阈值选择和独立测试集评估。

## 数据与防泄漏

- 使用既有 CVB 按 `group_id` 划分的 `val.csv` 和 `test.csv`。
- 由于全量测试基准约需 29.5 小时，第一轮按用户确认采用预先固定的类别分层子集：验证集每类最多 512 个，测试集每类最多 1024 个，种子为 `20260823`，以 `SHA-256(seed:sample_id)` 排序选取。
- 温度与拒识阈值只允许在验证集拟合。
- 测试集只运行一次最终评估，不参与参数选择。
- 保存检查点、验证清单、测试清单的 SHA-256，保证结果可追溯。
- 同时保存原始/选中样本数、抽样方法、种子、每类上限和选中样本 ID 的 SHA-256；抽样过程不得读取模型预测。
- 所有实验输出写入项目目录 `outputs/uncertainty/`，不修改外部 CVB 原始数据。

## 方法

### 温度缩放

模型输出 logits `z`，使用单一正温度 `T`：

`p = softmax(z / T)`

在验证集上最小化交叉熵拟合 `T`。温度用对数参数化确保为正，并限制在安全有限范围内。校准只改变置信度分布，不改变 argmax 分类结果。

### 不安全预测定义

当满足任一条件时，样本被视为不适合进入健康统计：

- 真实标签属于 `none`、`other`、`hidden`；
- 模型对可用行为的分类错误。

这一定义用于测量拒识器能否拦截错误或非可用结果，不等同于疾病识别。

### 联合拒识

拒识器使用两个可解释信号：

- 最大类别概率低于 `min_confidence`；
- 归一化预测熵高于 `max_normalized_entropy`。

阈值在验证集网格搜索。目标是在验证集可用行为覆盖率不低于 `0.60` 的条件下，优先最大化接受样本的 Macro-F1，再最小化选择性风险，最后优先较高覆盖率。若没有候选满足覆盖率约束，实验明确失败，不静默放宽标准。

## 对照组

1. `uncalibrated_fixed_045`：当前未校准概率与固定阈值 0.45。
2. `temperature_fixed_045`：温度缩放后仍使用固定阈值 0.45。
3. `temperature_joint_rejection`：温度缩放加验证集学习的最大概率/熵联合拒识。

## 指标

校准质量：

- Negative Log-Likelihood；
- Expected Calibration Error，固定 15 个等宽区间；
- Multiclass Brier Score。

分类与拒识质量：

- Accuracy、Macro-F1；
- Coverage；
- Selective Accuracy、Selective Macro-F1、Selective Risk；
- 不安全预测检测 AUROC 与 AUPRC；
- 每类支持度、接受数和拒识数。

没有接受样本时，选择性指标写为 `null`，不得伪造为零或满分。

## 软件边界

- `cattle_health_app/behavior/uncertainty.py`：纯数值校准、指标、阈值搜索和策略序列化。
- `cattle_health_app/behavior/uncertainty_experiment.py`：数据加载、模型推理、实验编排和命令行入口。
- `delivery_tests/test_behavior_uncertainty.py`：数值正确性、输入验证、防泄漏与确定性测试。
- `outputs/uncertainty/`：实验 JSON、逐样本 CSV 和答辩表格 CSV。

第一轮实验先生成离线结果。只有当测试集结果证明校准或拒识方案相对基线有明确收益时，才把策略接入实时 `BehaviorRuntime`；否则保留现有运行时并如实记录负结果。

## 成功标准

- 温度只用验证集拟合，测试集没有参数选择行为；
- 校准后的测试集 NLL 或 ECE 至少一项优于未校准基线；
- 联合拒识满足验证集覆盖率约束；
- 测试集结果完整报告覆盖率与选择性质量，不只报告被接受样本准确率；
- 相同输入、检查点和随机种子产生字节级一致的核心 JSON 指标；
- 新增单元测试和现有行为测试通过。

## 非目标

- 不在本阶段宣称疾病诊断或真正开放集识别；
- 不修改外部公开数据集；
- 不重新训练 X3D 主干；
- 不为了获得漂亮结果使用测试集选择温度或拒识阈值；
- 不在离线实验完成前改变线上告警逻辑。
