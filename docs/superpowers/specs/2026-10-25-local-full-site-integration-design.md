# 本机网站完整接入设计

日期：2026-10-25。用户明确选择“本机网站完整可用”。本轮不涉及公网服务器或域名。

## 用户可见结果

1. 双击项目 EXE 后，本机官网、工作台、API 可访问。档案和盘点从本机 SQLite 读取两组已标识的 `DEMO-` 数据。
2. 羊视频新任务默认使用本机已有、经 AUTH-Sheep 两段视频验证的 ICAERUS 羊专用研究候选；牛视频继续使用原交付权重。每个新视频结果必须记实际模型名称与 SHA-256，页面不得把旧任务说成新模型结果。候选权重保存在 Git 忽略目录，只在本机科研使用，缺失或哈希不符时拒绝声称已启用。
3. CattleBehaviours6 三类适配模型作为单牛裁剪短片的“研究试用”入口：只输出饮水、站立反刍、卧姿反刍三类概率和来源/限制；不替换日常 12 类行为分析、健康规则或历史 CBVD-5 指标。入口在研究证据区，模型缺失时明确不可用。

## 组件与数据流

- `model_registry` 校验羊候选和三类研究权重的固定摘要；`LocalMediaProcessor` 根据视频类别选择不同 YOLO 实例，保留现有牛链路。`VideoJobService` 在任务结果中写入检测器元数据。
- 行为研究 API 接收一个短片，保存于本机受控媒体目录，提取中央 2 秒的 16 帧，使用既有 X3D 预处理与三类 checkpoint 推理；返回概率、模型哈希、适用范围，不生成牛只健康结论。
- React 显示本机模型状态、视频任务实际模型、行为研究上传入口；档案与盘点沿用现有 API。页面清楚标记模拟资料与研究模型。
- 启动链路沿用 `XingMuLauncher.exe` / `start_delivery.ps1`；检查旧进程状态后安全启动，访问 API、网页和四块功能。
