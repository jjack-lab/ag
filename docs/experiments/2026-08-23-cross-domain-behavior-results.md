# CVB → CBVD-5 跨域牛只行为鲁棒性实验

## 当前状态

冻结协议已在真实 CBVD-5 连续视频上完成。`complete` 只表示推理、压力实验、报告和数值核对完成，不表示模型达到生产部署门槛。主结果是一个明确的跨域失效结论：现有 CVB 模型不能直接迁移到 CBVD-5。

## 零样本跨域结果

Macro-F1 只在当前映射层实际出现的目标类上做无权平均。NLL、ECE（15 个等宽置信度箱）和 Brier 都基于原始 12 类概率向量；拒识协议的概率指标只在被接受样本上计算，因此必须与覆盖率一起解释。

## 压力实验与数值核对

- 6 种退化：模糊、低照度、遮挡、降采样、丢帧和压缩；每种 4 级（0 为同一干净基准）。
- strict 每级 80 个逻辑样本，extended 每级 120 个；两层合计 200 个逻辑样本、173 个去重物理片段。
- 生成 96 行指标（2 层×2 协议×6 退化×4 级）和 18 个绑定条件的非零压力缓存。
- strict 已校准子集的干净 Macro-F1 为 0.0227；各退化三级结果介于 0.0000 与 0.0785。基线本身接近失效，曲线非单调且不能解释为某种退化“提升”了模型。
- strict 与 extended 的压力子集各自在层内固定，但跨层只有部分物理片段重合，因此只作层内对比，不声称跨层配对实验。
- 1000 条概率向量之和最大误差为 `4.44e-16`；原始/校准 argmax 0 个不一致；8 组接受数与指标文件全部吻合；所有覆盖率都在 `[0,1]` 且等于接受数/样本数；压力网格和每层样本数完整。

报告产物位于 `outputs/cross_domain/cvb_to_cbvd5/`：`metrics.json`、`protocol_comparison.csv`、`per_class_metrics.csv`、`risk_coverage.csv`、`stress_metrics.csv`、三张图和逐样本审计 CSV。原始概率缓存与逐样本预测不提交 Git。

## 少样本 Go/No-Go

门控结论为 `go_separate_adaptation_plan`，但本计划内不执行适配。原因是 strict 已校准零样本 Macro-F1=0.0048，小于 0.30，且四类独立源组数分别为饮水 66、采食 74、卧躺反刍 80、站立反刍 47，满足预留最终测试组后的最低组数条件。后续需要新建、重新冻结且按源视频隔离的少样本适配方案，不能在当前外测结果上调阈值或反复选模型。

## 结论与创新表达

当前可用于答辩和论文的创新点不是“现有模型已经跨域高准确”，而是形成了一条可审计的跨域安全评估链：严格/扩展语义边界、组隔离清单、冻结校准与拒识、质量证据、条件绑定压力缓存，以及失败时触发独立适配计划的门控。真实结果证明仅在单一训练域上表现良好的行为模型可能在公开外域上完全失效，也证明域内温度校准和简单拒识并不能自动解决域移问题。

## 结论边界

- 只支持公开数据条件下的牛只行为识别鲁棒性描述，不支持疾病诊断或核心体温测量。
- CBVD-5 是单一外部数据集，片段来自官方标注时刻的虚拟裁剪，不代表真实牧场长期运行。
- 质量门是预声明启发式而非学习型门，结果是探索性证据，不声称质量拒识获得提升。
- 人工静态审计不能独立确认饮水和反刍等动态标签；公开标注噪声仍可能存在。
- 极低基线使压力曲线缺少可解释的性能余量；不能据此比较退化敏感性的因果强弱。
- 不支持无人值守生产部署，现阶段原型应显示失败边界、拒识与证据链，而不是隐藏低指标。
