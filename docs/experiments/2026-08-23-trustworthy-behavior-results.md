# 可信牛只行为识别实验结果

## 结论

现有 X3D 检查点明显欠置信。仅使用验证集拟合温度并冻结拒识策略后，独立测试子集上的校准误差显著下降，并在保留约六成真实可用行为的同时降低了接受样本的错误风险。预定义运行时接入门槛全部满足。本轮熵阈值未显示超出校准固定阈值的额外测试收益。

## 可复现设置

- 检查点 SHA-256：`731c6ed39dcf002915e888c829e1f86727f815331a2b3c21d06a17d40d62a08e`
- 模型版本：`cvb-x3d-v1`
- 抽样：按类别和 `SHA256(seed:sample_id)` 确定性排序，种子 `20260823`
- 验证集：每类最多 512 条，共 2,897 条；只用于拟合温度和选择策略
- 测试集：每类最多 1,024 条，共 10,548 条；只用于最终评估
- 温度：`0.3334679763`
- 冻结策略：最大概率不低于 `0.45`，归一化熵不高于 `0.85`
- 最低可用行为覆盖率约束：`0.60`
- 产品有效接受还要求预测标签不是 `none`、`other`、`hidden`

三种方案的整体 Accuracy 均为 `0.4628`、整体 Macro-F1 均为 `0.4177`，因为温度校准不改变 argmax 类别；收益来自可信度质量和“允许拒绝”后的风险—覆盖率权衡。旧阈值接受率为零，是因为未校准最大置信度最高约为 `0.1982`。校准后固定阈值原始通过率为 `73.18%`，排除预测为数据集不确定类后，产品有效覆盖率为 `55.43%`。

## 论文与答辩表述边界

推荐创新点表述为“面向真实牧场噪声视频的校准型选择性行为识别”或“带风险—覆盖率约束的可信牛只行为识别”，不要表述为已经完成完整开放集识别。CVB 的 `none`、`other`、`hidden` 是数据集原生类别，不是训练时未见的新类别；严格开放集结论仍需留一行为类重训练或额外域外数据实验。

该测试集是确定性类别分层子集，适合在 1–3 个月周期内做方法消融，但其类别分布与原始不均衡验证集不同，指标不能直接横向比较。验证子集只包含 8 类；测试子集包含 11 类，其中 `ruminating-lying`、`resting-lying`、`running` 在阈值选择中没有验证样本，应视为外推测试。这不会造成 validation/test 泄漏，但会限制策略对全部类别的证据强度。行为结果只用于研究性风险筛查，不是体温测量或疾病诊断。
