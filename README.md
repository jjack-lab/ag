# 星牧智控整合版

这是 E、F 两盘项目成果的独立整合版本，项目目录为 `F:\new大创`。原项目不会被本项目覆盖或修改。

当前版本面向可运行演示，已经接通：

- YOLO11 牧场牲畜图片检测；
- 本地视频异步检测；
- ByteTrack 持续跟踪和 Track ID；
- 带框图片、带跟踪视频和轨迹 CSV；
- 静止、离群、活动量下降等规则型健康风险提示；
- **Isolation Forest 轨迹异常检测**：与牛群整体对比，识别活动模式偏离的个体；
- 健康告警 CSV、个体汇总 CSV 和 HTML 报告；
- SQLite 任务与告警记录；
- FastAPI 后端与 React 浏览器控制台。

健康风险结果用于辅助筛查，不是兽医疾病诊断。

## 使用方式

### 图片检测

1. 打开 Web 控制台。
2. 进入智能识别工作台并选择图片识别。
3. 上传 JPG、JPEG、PNG 或 BMP。
4. 设置置信度、IoU和类别过滤。
5. 开始识别，查看并下载带框结果。

### 视频检测与健康风险提示

1. 切换到视频识别。
2. 上传 MP4、AVI、MOV 或 MKV。
3. 选择 ByteTrack 或 BoT-SORT。
4. 提交任务并等待进度到达完成。
5. 播放带 Track ID 的结果视频。
6. 下载结果视频、轨迹、告警、个体健康汇总和 HTML 报告。

视频完成后，结果页还会显示**健康证据图谱**：按视频内 Track ID 串起规则观察（含发生秒数）、既有风险评分和人工复核建议。图谱使用本次视频生成的告警与健康汇总；低风险且无告警的轨迹也会明确显示“未触发规则告警”。同页可回看带框视频并下载原始证据文件。Track ID 只在本段视频内有效，不能跨视频认作同一只动物。

视频模式下的“最近视频任务”可以在刷新页面后重新打开已完成结果。打开任务后，在“人工复核记录”里填写漏检、ID 切换、误告警或现场健康关注，可选填视频内 Track ID 与秒数，记录人工结论和说明。现场核对耳标后，在“跨视频个体档案”里把该视频的 Track ID 关联到稳定个体编号；第二天的视频可关联到同一编号，档案会按日期显示视频证据和人工复核。关联由人确认，系统不会自动把两段视频认作同一动物。

视频结果页下方的“人工核查事项”可填写事项、负责人和完成时间；有带时间点的规则提示时，也可在事件时间轴点击“根据此提示创建核查事项”，自动带入视频内 ID 与秒数，再由人工补全并提交。全局“处置待办”集中显示待处理、逾期和待复查事项，可记录现场处理、设置下次复查时间、关闭事项，并点击“打开视频证据”回到关联的视频结果。规则提示只是核查线索，事项结论由人员填写；系统不会据此诊断疾病。

### 圈舍存栏核对

在“实时监控 → 视频识别”打开已完成的牛或羊视频，结果下方的“圈舍存栏核对”可填写圈舍编号、登记存栏数及来源、人工清点数、拍摄覆盖范围和操作人。“圈舍盘点”导航按每页 20 条浏览全部历史记录，可输入圈舍编号并按盘点状态筛选；筛选后从第一页开始。清点数留空表示尚未清点，填 0 表示人工确认清点为零；尚未完成首次人工清点时不能进入复核。视频 Track ID 只作画面定位参考，不参与存栏差额计算。

在全局“圈舍盘点”历史卡片中点击“打开视频证据”，系统会读取该记录绑定的已完成视频任务，切换到“实时监控”，并直接显示对应的结果播放器、视频内 Track ID、事件、纠错与人工复核信息。任务不存在、尚未完成或没有结果时，页面留在圈舍盘点并显示错误。筛选和翻页不会改变记录绑定的视频任务。

视频结果内的“圈舍存栏核对”直接按当前视频任务查询全部关联盘点记录；即使全局已有超过 100 条更新的盘点，旧视频的记录仍可在结果页回看。全局历史页继续独立分页和筛选。

拍摄覆盖不完整时，页面要求补拍并重新建盘点；完整覆盖后若登记数与清点数不符，只显示待复点。人工复点可记录数量仍少、数量超出或数量相符；若需登记丢失，还必须填写丢失数量、复核人和说明，并确认已核对出入栏记录、已完成现场查找。该结论标为人工记录，系统不自动判定动物丢失。建议现场先用真实圈舍台账、完整拍摄和实地清点做验收，再用于经营决策。

首页看板的“最近牛视频 Track ID 数”只取最近一次已完成的牛视频，并显示该任务处理时间；它不是今日存栏数。没有已完成牛视频时显示“暂无记录”，处理过但没有识别出轨迹时才显示 0。“历史高风险规则提示”和“历史未处理规则提示”均统计所有视频留下且未处理的提示条数，不代表当前有多少头牛。首页的“牛只档案”也不再按临时 Track ID 跨视频合并个体；跨视频关联需在视频结果页由人核对耳标。

“事件时间轴”汇集带秒数的规则提示、行为切换、复核与画面纠错，点击时间可定位结果视频，也可下载约 6 秒的证据片段；全视频统计没有精确时刻，不进入时间轴。“画面人工纠错”可暂停视频拖拽标出漏检框，或指定错误 Track ID、牛只行为标签，保存后可导出 CSV。人工修正独立保存，不覆盖原模型输出。

“数据分析 → 公开数据评测中心”可为已完成的牛羊视频导入公开数据的逐帧标注。CSV 须含 `frame_index,class_id,track_id,x,y,width,height`，帧号从 0 开始，框坐标为归一化左上角坐标和宽高；只评测带标注的帧。页面要求登记数据名称、来源 URL、版本、许可和开发/验证/外部测试划分，并保存视频与标注 SHA-256。评测输出 IoU≥0.5 的 Precision、Recall、F1、TP/FP/FN，以及匹配帧上的 ID 切换次数；数据来源和许可由使用者登记，系统不会自动验证，也不会在没有标注时生成分数。

个体档案还可录入现场回访；如录入兽医诊断，必须填写诊疗记录出处。此处只保存用户录入的信息，界面明确标为“未独立核验”，不会自动生成疾病名称或发病时间预测。后续须取得新牧场视频、真实病例、诊疗或检验结果，定义诊断口径并做独立验证，才能评估预测模型。

演示牛只时，在“识别类别”选择“牛”（或保持视频默认牛）。演示羊只时选择“羊”，系统可输出羊的检测框、Track ID、追踪视频和轨迹 CSV。**羊的健康规则、行为识别及疾病推断尚未验证**，页面会直接说明此边界，不展示牛用健康评分或牛用健康报告。即使选择羊，也不将牛行为模型加载到羊的视频上。

羊视频现在还会给出基于相邻检测框位移的“低位移 / 移动 / 快速移动”时长与切换时间点。这是规则型轨迹活动量，不能辨认采食、坐卧等具体行为，也不是健康分数；镜头运动、透视、遮挡和 ID 切换会影响数值。稳定个体编号由现场人员关联后，档案会显示牛的多次规则风险分，或羊的多次移动占比；至少两次有效视频才绘制趋势，趋势不预测疾病。[Mendeley 羊行为集](https://data.mendeley.com/datasets/w65pvb84dg/1)为整段视频级标签且含混合活动片段，未取得可用于本机训练的原视频与独立验证前，不把它训练成逐羊行为结论。

已用 ICAERUS 公开羊视频实际运行交付模型与来源明确的羊专用模型，并生成带紧凑检测框、Track ID、逐帧数量和画面位移说明的 H.264 演示视频。观看路径、测量结果、模型来源与使用边界见 [ICAERUS 羊视频模型演示记录](docs/2026-10-14-icaerus-sheep-model-demo.md)。羊专用权重只用于这次单独保存的演示运行，产品默认权重未被替换。

答辩时可以按“上传牧场视频 → 播放识别追踪结果 → 查看某个 Track ID 的证据链 → 下载报告并说明需现场复核”展示。当前的风险评分是规则型辅助筛查，不是某种疾病的概率，也不能预测发病时间。若要展示具体疾病名称，应先取得牧场确认病例、诊疗或检验结果及同一动物的多日视频，定义病例口径并完成独立验证；在此之前不要把现象直接命名为疾病。

视频处理先使用 OpenCV 写入，再在找到 FFmpeg `libx264` 时自动转成浏览器可播放的 H.264 MP4；事件片段同理。转换失败会保留原 `mp4v` 文件并写日志，此时仍可下载后用本地播放器查看。本机 PyTorch 环境已带 FFmpeg；其他电脑须安装支持 `libx264` 的 FFmpeg 并加入 PATH，或放在 Python 环境的 `Library/bin/ffmpeg.exe`。

视频为后台任务。浏览器会显示按已处理帧数计算的真实进度，任务失败时 API 会保存失败状态和错误信息。默认单个上传文件上限为512MB，可通过 `AGRINEBULA_MAX_UPLOAD_MB` 调整。

### 可信行为识别：置信度校准与联合拒识

项目已对固定检查点完成一组预注册口径的后处理实验：仅用验证集拟合温度并选择阈值，再在独立测试集评估。确定性类别分层子集使用种子 `20260823`，验证集 2,897 条、测试集 10,548 条；外部 CVB 原始数据全程只读。拟合温度为 `0.3334679763`，冻结策略为最低置信度 `0.45`、最高归一化熵 `0.85`。

在该平衡测试子集上，未校准 ECE 为 `0.2857`，温度校准后为 `0.0753`；未校准固定 `0.45` 阈值接受率为 `0%`，校准后产品有效覆盖率为 `55.43%`、真实可用行为覆盖率为 `62.89%`，接受样本 Macro-F1 为 `0.5589`，选择性风险为 `0.4192`。本轮验证集选择出的熵阈值没有在测试集上带来超出校准固定阈值的额外收益，因此应把主要实证贡献归因于温度校准和数据集不确定预测过滤，而不是宣称熵门槛已显著增益。

运行时会自动读取与检查点同目录的 `cvb_x3d_v2_calibration.json`，并严格校验模型版本和 SHA-256；可用 `AGRINEBULA_BEHAVIOR_CALIBRATION` 指定其他匹配产物。时间线额外记录校准置信度、归一化熵、拒识原因和温度。这里的 `none`、`other`、`hidden` 是 CVB 数据集原生标签，因此当前结论是“低可信与不安全预测拒识”，不是严格的开放集识别；平衡子集指标也不能与上面的原始不均衡验证集指标直接横向比较。验证子集只覆盖 8 类，测试子集覆盖 11 类，其中 `ruminating-lying`、`resting-lying`、`running` 未参与阈值选择，属于外推评估，不能据此声称所有类别均已充分验证。

视频任务会新增：

- 带 Track ID、中文行为和置信度的结果视频；
- `*_behavior.csv` 行为时间线；
- `*_behavior_summary.csv` 逐轨迹行为汇总；
- `*_behavior_report.json` 结构化研究报告；
- 页面中的行为时长、有效行为占比和无法确定时长。

可通过 `AGRINEBULA_BEHAVIOR_MODEL` 指定其他兼容检查点。自定义检查点没有匹配校准文件时沿用原固定阈值；若存在校准文件但哈希或版本不匹配，则拒绝加载该行为运行时，避免误用阈值。行为权重缺失、损坏或推理失败时，YOLO 检测、跟踪、轨迹和原有规则健康分析仍会继续运行，页面会明确显示降级状态。

## 轨迹异常检测（Isolation Forest）

视频任务在完成检测与跟踪后，会以牛群整体为参照做**无监督轨迹异常检测**（`scikit-learn` Isolation Forest）：

- 每头牛按轨迹计算 15 维特征：速度均值/标准差/峰值、加速度、活动半径、总位移与蜿蜒度、与牛群质心的平均/最近距离、与最近同伴距离、检测框纵横比与面积；
- 同一视频内横向对比：活动模式偏离牛群整体的个体被标记为异常，输出 0–1 异常得分与主要差异特征；
- 产物：`*_trajectory_anomaly.csv`（每头牛一行，含全部特征与异常标记）；页面展示异常牛列表，异常个体同时写入 SQLite 告警（类型 `trajectory_anomaly`，中等风险）；
- 牛只数量不足（默认少于 5 头可对比轨迹）时跳过检测并如实显示原因，不影响规则健康分析；
- 该检测是**研究性辅助筛查**：无监督结果用于提示"与群体不同"的个体，不替代兽医诊断。静态场景（如本项目的验收视频）中差异主要来自检测框面积（透视近大远小）与群体距离，需结合场景解读。
